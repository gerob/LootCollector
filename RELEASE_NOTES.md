# LootCollector 1.0.3r-beta

## Features

- **Two-row Discoveries filters** — Looted, Date, and Undiscovered stay on the tab row with Clear on the right; Source, Quality, Type, Slots, Usable By, Favorites, Enchant, and related dropdowns move to a second row.
- **Stats filter** — Categorized dropdown (Primary / Melee / Spell / Defense / Misc) that adds or removes search chips for tooltip stats.
- **Enhanced WF Tooltip in Settings** — Toggle under Settings → Viewer Setup (same option as the map menu and `/lcwf`).
